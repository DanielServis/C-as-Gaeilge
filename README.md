S'eard atá i gceist leis an dtionscnamh seo ná chun blaosc Gaeilge a chaitheamh are an sean-tiomsaitheoir C "gcc",
ionas go mbeidh daoine timpeall an domhain lán ablta ríomhchlarú a dhéanamh nó a fhoghlaim trí mheán na Gaeilge.

Úsáid:
  1. Cinntigh go bhfuil gcc íoslódáilte agat
  2. Cruthaigh comahad i gcruth sampla.cf
  3. Bain úsáid as an tiomsaitheoir "cft" (./cft ionchar.cf aschur)
  4. Rith an t-aschur i gcruth ./sampla (is gnáth comhad dénártha é ag an bpointe seo)
